# Sample Financial Documents

This directory is for financial documents to test the system.

## Where to get public financial documents

### Indian Companies (BSE/NSE)
- BSE India: https://www.bseindia.com (listed company filings)
- NSE India: https://www.nseindia.com (annual reports section)

### US Companies (SEC EDGAR)
- https://www.sec.gov/edgar/searchedgar/companysearch.html
- Download 10-K (annual) or 10-Q (quarterly) filings as PDF

### Example documents to try:
- Any company's Annual Report PDF (search '[Company Name] Annual Report 2024 PDF')
- Quarterly earnings press releases
- Investor day presentations (usually on company IR pages)

## Important Notes
- Do NOT commit copyrighted documents to GitHub
- Add *.pdf and *.docx to .gitignore (already done)
- This README is safe to commit
- For testing, a 10-20 page document works well before trying 200+ page reports
